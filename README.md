# 聖誕探索號：12 格版

適合教會兒童聖誕活動的多人互動遊戲。主持人使用控制台操作，玩家透過獨立投影畫面觀看 12 格環狀棋盤。

## 遊戲內容

- 兩隊輪流擲六面骰並沿棋盤移動。
- 保留原版的再擲一次、暫停一輪、退後、團隊任務、問答、手動移動與抵達終點獲勝機制。
- 主控台位於 `/`，投影畫面位於 `/game`；兩個畫面透過 Socket.IO 即時同步。
- 夢夢車站是起點，思麥特車站是終點。

## 12 格順序

1. 夢夢車站（起點）
2. 馴鹿加速（再擲一次）
3. 冰雪路障（暫停一輪）
4. 禮物工坊（傳送禮物）
5. 聖誕知識站（耶穌誕生地問答）
6. 雪人暖身站（原地跑步 10 秒）
7. 清除積雪（合作傳送道具）
8. 聖誕合照站（全隊合照動作）
9. 暴風雪（退後 2 格）
10. 雪橇維修站（傳送工具、模擬維修）
11. 聖誕派對（跟著主持人做動作）
12. 思麥特車站（終點）

## 啟動方式

```bash
npm install
cd server && npm install && cd ..
npm run dev:all
```

開啟 [http://localhost:3000](http://localhost:3000) 設定隊伍，再按「開啟投影畫面」或前往 [http://localhost:3000/game](http://localhost:3000/game)。投影時可使用右上角按鈕切換全螢幕。

要單獨啟動時，分別執行 `npm run dev` 與 `npm run dev:server`。預設前端位於 3000 埠，Socket.IO 後端位於 3001 埠。

## 建置

```bash
npm run build
```
